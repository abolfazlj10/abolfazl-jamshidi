# Project cover generation — revised direction

Final assets: `public/projects/idiomyar-cover.webp`, `public/projects/toolbo-cover.webp`, and `public/projects/avani-cover.webp` (1672 × 941, WebP). ToolBo was generated with the built-in image generation tool. IdiomYar uses a typographic SVG source, and Avani uses an SVG composition with an embedded application screenshot, both exported to WebP.

Each cover has its own composition; the Fash device mockup is no longer used as a reference. Source application screenshots are preserved. Avani's cover uses a crop of its real interface with customer details concealed; the other covers use typography or conceptual product illustrations.

## idiomyar

Source: `public/projects/idiomyar-cover.svg`.

Minimal typography on a flat warm off-white background. A centred dark wordmark with a blue accent on “Yar”, and the existing product tagline, “Idioms that stay with you.” Generous empty space keeps the cover readable in the project grid. No textures, mockups, shadows, or illustrations.

Export at the source size (1672 × 941) using Sharp with WebP quality 95. The portfolio continues to use `idiomyar-cover.webp`.

## toolbo

Reference: `/Users/abolfazl/workspace/abolfazl/public/projects/toolbo.png`

Use case: ads-marketing. Create a distinctive premium portfolio cover for toolbo., a practical calculator and converter toolbox. Landscape 16:9, 1672x941. Reference image supplies exact wordmark four-square symbol and forest green / lime / warm cream brand palette only. New composition: beautiful top-down modular physical bento tray on warm ivory seamless background. A bold dark forest green rectangular tile centered contains exact 'toolbo.' wordmark with four-square logo and plenty of negative space. Around it tightly composed precision-crafted rounded tiles: tactile calculator keys with numerals and + = signs, calendar tile with a clean abstract 7-column grid, ruler markings, a large % symbol, opposing conversion arrows, clock dial. Varied tile sizes arranged in an elegant staggered grid, ivory ceramic, matte green and translucent lime acrylic materials, editorial product photography, warm directional daylight from upper left, realistic subtle shadows. Tiles feel like software utilities translated into sculptural objects, not hardware tools. Keep composition within center 80% so cropping stays graceful. No laptop, phone, browser window, screenshot, dark backdrop, neon stripe, metal toolbox, screwdrivers, random decorative objects, additional text or invented slogans. Confident recognizable brand and sophisticated minimalist still life.

## avani

Source: `public/projects/avani-cover.svg`.

An editorial composition on a flat pale lavender background (`#e8e3f0`). A large aubergine Avani wordmark (`#392c48`) and product descriptor occupy the upper left; the category and a fine arrow align to the upper right. A large, straight-on crop of `public/projects/avani/orders-board.webp` fills the lower portion and extends beyond the bottom edge. The SVG embeds the source screenshot as PNG data and overlays neutral lines on visible customer names and phone numbers. No perspective, gradients, shadows, textures, or 3D objects.

Export at the source size (1672 × 941) using Sharp with WebP quality 95. The portfolio continues to use `avani-cover.webp`.
