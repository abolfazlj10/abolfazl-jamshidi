# Portrait asset

The original portrait was supplied by Abolfazl for this portfolio.

- Original: `public/images/abolfazl.png`
- Website cutout: `public/images/abolfazl-cutout.png`
- Optimized website asset: `public/images/abolfazl-cutout.webp` (same cutout, WebP compression).
- Tool: built-in image generation, background extraction mode.
- Prompt: Remove only the gray background and replace it with genuine transparency. Preserve the person's face, identity, expression, gaze, hair, beard, pose, body, shirt, grayscale photography, lighting, proportions, and framing. No beautification, retouching, colorization, text, or additions.

The original remains unchanged. The website fades only the lower edge of the
cutout with CSS to blend it into the page.
