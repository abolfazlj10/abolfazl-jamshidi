# J10 Projects

ویترین فارسی پروژه‌های ابوالفضل جمشیدی؛ هر کارت به نسخهٔ مستقل و کد همان پروژه لینک می‌شود.

## اجرای محلی

به Node.js نیاز دارد و هیچ وابستگی نصب‌شدنی ندارد:

```sh
npm run dev
```

نشانی: http://127.0.0.1:4317

```sh
npm run check
```

## ویرایش پروژه‌ها

داده‌ها در `dist/projects.json` هستند. برای اضافه کردن پروژه، یک رکورد با شناسهٔ یکتا، عنوان، توضیح، دسته، فناوری‌ها و لینک‌های مخزن و دمو اضافه کنید. تعداد مجموعه در متن آغاز صفحه و دکمهٔ «همهٔ پروژه‌ها» در `dist/index.html` را نیز به‌روز کنید.

`status` یکی از `available`، `unavailable` یا `unverified` است. دکمهٔ اجرای پروژه فقط برای وضعیت `available` نمایش داده می‌شود. هیچ لینک اجرایی حدس زده نشده است.

## امکانات

- رابط راست‌به‌چپ و واکنش‌گرا با فونت محلی وزیرمتن
- جست‌وجو بر اساس نام فارسی، نام انگلیسی، توضیح و فناوری‌ها
- یکسان‌سازی ی/ي، ک/ك، فاصله و نیم‌فاصله در جست‌وجو
- دسته‌بندی و حالت بدون نتیجه با امکان پاک کردن فیلترها
- لینک‌های مستقل با نام دسترس‌پذیر و باز شدن در تب جدید
- میان‌بر `/` برای جست‌وجو، پیمایش با صفحه‌کلید و رعایت کاهش حرکت

## منابع و وضعیت لینک‌ها

منبع اطلاعات: مخازن عمومی حساب [abolfazlj10](https://github.com/abolfazlj10)، توضیحات مخزن، README، package.json و فایل‌های مربوط به رابط پروژه. بررسی در ۲۰۲۶-۱۰-۰۷ انجام شده است.

| پروژه | مخزن | وضعیت بارگذاری صفحهٔ دمو |

| Weather App | https://github.com/abolfazlj10/WeatherApp | HTTP 200 |

این بررسی، دسترسی به صفحهٔ ورودی را تأیید می‌کند؛ عملکرد داخلی و سرویس‌های هر برنامه جداگانه آزمایش نشده‌اند. وضعیت‌ها دادهٔ ثابت هستند و پایش زنده نیستند. ریپوهای سازمانی و پروژه‌های خصوصی در این ویترین وارد نشده‌اند.

تصویر تولبو از `.codex-home-desktop-settled.png` در ریپوی خود پروژه گرفته شده است؛ ممکن است با نسخهٔ فعلی دمو تفاوت داشته باشد. فونت‌ها از دارایی‌های همان مخزن گرفته شده‌اند و مجوز وزیرمتن در `dist/assets/Vazirmatn-LICENSE.txt` نگهداری می‌شود.

## انتشار

تمام خروجی قابل ارائه در پوشهٔ `dist/` است؛ نیازی به مرحلهٔ build ندارد و روی میزبان‌های فایل ایستا قابل انتشار است. اطلاعات اتصال نسخهٔ Sites در `.openai/hosting.json` قرار دارد و هیچ توکن یا کلیدی در سورس نگهداری نمی‌شود.

## بررسی انجام‌شده

بررسی ساختار اطلاعات، یکتایی شناسه‌ها، لینک‌ها و وجود فایل‌های ضروری؛ بررسی دستی در مرورگر برای جست‌وجوی فارسی، دستهٔ بازی، حالت بدون نتیجه، بازنشانی فیلترها و نمایش در عرض ۳۹۰ پیکسل بدون سرریز افقی.
