# J10 Projects

پورتفولیوی انگلیسی ابوالفضل جمشیدی، ساخته‌شده با **Next.js App Router** و React.

در **صفحهٔ اصلی ← Intro**، معرفی کوتاه، عکس و مسیر ورود به نمونه‌کارها دیده می‌شود. **Projects** هفت پروژه را با پیش‌نمایش واقعی، توضیح مختصر، فناوری‌ها و لینک دمو و کد معرفی می‌کند. ToolBo و IdiomYar اول فهرست هستند. بخش **Let’s talk** مسیر تماس را در پایان صفحه قرار می‌دهد.

در دسکتاپ با عرض حداقل ۱۰۰۰ و ارتفاع حداقل ۷۲۰ پیکسل، قاب پروژه‌ها هنگام اسکرول ثابت می‌ماند و با پیشروی طبیعی صفحه، پروژهٔ فعال تغییر می‌کند. هیچ رویداد wheel مسدود نمی‌شود؛ از ابتدا و انتهای فهرست می‌توان به بخش قبل و بعد رفت. نام پروژه‌ها و دکمه‌های قبلی/بعدی برای انتخاب مستقیم در دسترس‌اند. کلیدهای چپ/راست و Home/End در کنترل‌های پروژه نیز کار می‌کنند.

در موبایل و تبلت، انتخاب **Choose a project** و دکمه‌های قبلی/بعدی بالای پیش‌نمایش قرار دارند. حرکت افقی روی پیش‌نمایش پروژه را عوض می‌کند و حرکت عمودی برای اسکرول طبیعی صفحه آزاد است. در نمایشگرهای کوتاه هم بخش پروژه‌ها ارتفاع طبیعی دارد تا محتوا بریده نشود.

اطلاعات پروژه‌ها هنگام build داخل صفحه قرار می‌گیرد. حرکت‌ها کوتاه‌اند و گزینهٔ کاهش حرکت سیستم رعایت می‌شود. برای نمایش پورتفولیو API یا سرویس سمت سرور لازم نیست. بدون جاوااسکریپت، لینک مستقیم همهٔ پروژه‌ها در دسترس می‌ماند.

## اجرا

Node.js 22 یا جدیدتر:

```sh
npm ci
npm run dev
```

نشانی محلی: http://127.0.0.1:4317

## ساخت نسخهٔ نهایی

```sh
npm run build
```

خروجی در `out/` تولید می‌شود. این یک پروژهٔ واقعی Next.js است که با قابلیت [Static Export](https://nextjs.org/docs/app/guides/static-exports) خروجی قابل میزبانی روی سرویس‌های فایل ایستا می‌سازد.

## ساختار

- `app/page.js`: معرفی، نمونه‌کارها و تماس
- `app/project-showcase.js`: نمایش پروژه و هماهنگی انتخاب با اسکرول طبیعی
- `app/project-scroll.mjs`: محاسبهٔ پروژهٔ فعال و جایگاه اسکرول
- `app/layout.js`: زبان انگلیسی، فونت محلی و اطلاعات صفحه
- `app/globals.css`: ظاهر تیره و چیدمان واکنش‌گرا
- `data/projects.json`: ترتیب، توضیحات و لینک پروژه‌ها
- `public/projects/`: پیش‌نمایش واقعی پروژه‌ها
- `next.config.mjs`: تنظیم خروجی ایستا

برای افزودن یا ویرایش پروژه‌ها `data/projects.json` را تغییر بده. برای دموی در دسترس، `status` را برابر `available` بگذار. سایر وضعیت‌ها به‌جای لینک اجرا، `Demo currently offline` نشان می‌دهند.

## آزمون

```sh
npm test
npm run build
```

آزمون‌های واحد، محدودماندن انتخاب به ابتدا و انتهای فهرست، هماهنگی انتخاب مستقیم با اسکرول و رفتار اندازه‌های مختلف را بررسی می‌کنند.

آزمون مرورگر در `tests/browser.mjs` قرار دارد و به Playwright و Chrome نیاز دارد. با سرور محلی روشن:

```sh
node tests/browser.mjs
```

اگر Playwright خارج از پروژه نصب شده، مسیر بسته را در `PLAYWRIGHT_MODULE` بده. `TEST_URL` و `TEST_SCREENSHOTS` نیز قابل تغییرند. سناریوها شامل ورود و خروج طبیعی از پروژه‌ها، انتخاب مستقیم، صفحه‌کلید، لینک‌ها، اندازه‌های موبایل و کاهش حرکت هستند.

## منابع

نام‌ها و لینک‌ها از ریپوهای عمومی [abolfazlj10](https://github.com/abolfazlj10) گرفته شده‌اند: ToolBo، WeatherApp، calculator، TicTacToe، todo-List، IdiomYar و CPass.

در بررسی ۲۰۲۶-۱۰-۰۷، صفحهٔ ورودی شش دمو در دسترس بود؛ آدرس CPass خطای ۴۰۴ داشت. این وضعیت‌ها ثابت‌اند و به معنای پایش زنده یا آزمون کامل عملکرد پروژه‌های مستقل نیستند.
