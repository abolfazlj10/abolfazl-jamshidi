# J10 Projects

پورتفولیوی انگلیسی ابوالفضل جمشیدی، ساخته‌شده با **Next.js App Router** و React.

بخش `Intro` عکس، نام و معرفی کوتاه را نمایش می‌دهد. بخش `Projects` هفت پروژه را روی یک مسیر چرخشی نشان می‌دهد: پروژه قبلی بالا سمت راست، پروژه فعال در مرکز و کمی سمت چپ، و پروژه بعدی پایین سمت راست.

اسکرول رو به پایین پروژه بعدی را فعال می‌کند؛ رو به بالا جهت حرکت را برمی‌گرداند. آخر و اول فهرست به هم متصل‌اند. آیکون‌ها، فلش‌ها و نشانگرهای پایین هم برای انتخاب مستقیم قابل استفاده‌اند. در موبایل روی آیکون‌ها حرکت عمودی انجام بده یا از فلش‌ها استفاده کن. لینک `Intro` در بالای بخش پروژه‌ها به معرفی برمی‌گردد؛ سمت چپ صفحه نیز اسکرول عادی دارد.

اطلاعات پروژه‌ها هنگام build داخل صفحه قرار می‌گیرد. حرکت با Motion اجرا می‌شود و گزینه کاهش حرکت سیستم رعایت می‌شود. هیچ API یا سرویس سمت سروری برای نمایش پورتفولیو لازم نیست.

## اجرا

Node.js 22 یا جدیدتر:

```sh
npm ci
npm run dev
```

نشانی محلی: http://127.0.0.1:4317

## ساخت نسخهٔ نهایی

```sh
npm run build
```

خروجی در `out/` تولید می‌شود. این یک پروژهٔ واقعی Next.js است که با قابلیت [Static Export](https://nextjs.org/docs/app/guides/static-exports) خروجی قابل میزبانی روی سرویس‌های فایل ایستا می‌سازد.

## ساختار

- `app/page.js`: معرفی و ساختار صفحه
- `app/project-wheel.js`: حرکت، ورودی اسکرول، لمس و صفحه‌کلید
- `app/wheel-math.mjs`: موقعیت پروژه‌ها روی مسیر چرخشی
- `app/layout.js`: زبان فارسی، فونت محلی و اطلاعات صفحه
- `app/globals.css`: ظاهر مشکی و واکنش‌گرا
- `data/projects.json`: نام‌ها و لینک پروژه‌ها
- `public/favicon.svg`: آیکون سایت
- `next.config.mjs`: تنظیم خروجی ایستا

برای افزودن یا ویرایش پروژه‌ها `data/projects.json` را تغییر بده. برای دموی در دسترس، `status` را برابر `available` بگذار. سایر وضعیت‌ها به‌جای لینک اجرا، `Live demo offline` نشان می‌دهند. عکس‌های پیش‌نمایش واقعی پروژه‌ها در `public/projects/` قرار دارند.

## آزمون

```sh
npm test
```

آزمون مرورگر در `tests/browser.mjs` قرار دارد و به Playwright و Chrome نیاز دارد. با سرور محلی روشن:

```sh
node tests/browser.mjs
```

اگر Playwright خارج از پروژه نصب شده، مسیر بسته را در `PLAYWRIGHT_MODULE` بده. `TEST_URL` و `TEST_SCREENSHOTS` نیز قابل تغییرند. آزمون شامل حلقه کامل، حرکت معکوس، موقعیت آیکون‌ها، صفحه‌کلید، لمس، کاهش حرکت و اندازه‌های موبایل و دسکتاپ است.

## منابع

نام‌ها و لینک‌ها از ریپوهای عمومی [abolfazlj10](https://github.com/abolfazlj10) گرفته شده‌اند: ToolBo، WeatherApp، calculator، TicTacToe، todo-List، IdiomYar و CPass.

در بررسی ۲۰۲۶-۱۰-۰۷، صفحهٔ ورودی شش دمو در دسترس بود؛ آدرس CPass خطای ۴۰۴ داشت. این وضعیت‌ها ثابت‌اند و به معنای پایش زنده یا آزمون کامل عملکرد پروژه‌های مستقل نیستند.

فونت وزیرمتن به‌صورت محلی استفاده شده؛ مجوز در `app/fonts/Vazirmatn-LICENSE.txt` است. هیچ کلید یا توکنی در سورس نیست.
