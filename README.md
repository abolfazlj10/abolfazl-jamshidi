# J10 Projects

ویترین بسیار سادهٔ پروژه‌های ابوالفضل جمشیدی، ساخته‌شده با **Next.js App Router** و React.

یک صفحه، فهرست هفت پروژه و لینک‌های «اجرا» و «گیت‌هاب». اطلاعات پروژه‌ها هنگام build داخل صفحه قرار می‌گیرد؛ جست‌وجو، فیلتر، فرم یا درخواست API در مرورگر ندارد.

## اجرا

Node.js 22 یا جدیدتر:

```sh
npm ci
npm run dev
```

نشانی محلی: http://127.0.0.1:4317

## ساخت نسخهٔ نهایی

```sh
npm run build
```

خروجی در `out/` تولید می‌شود. این یک پروژهٔ واقعی Next.js است که با قابلیت [Static Export](https://nextjs.org/docs/app/guides/static-exports) خروجی قابل میزبانی روی سرویس‌های فایل ایستا می‌سازد.

## ساختار

- `app/page.js`: فهرست پروژه‌ها
- `app/layout.js`: زبان فارسی، فونت محلی و اطلاعات صفحه
- `app/globals.css`: ظاهر ساده و واکنش‌گرا
- `data/projects.json`: نام‌ها و لینک پروژه‌ها
- `public/favicon.svg`: آیکون سایت
- `next.config.mjs`: تنظیم خروجی ایستا

برای افزودن یا ویرایش پروژه‌ها فقط `data/projects.json` را تغییر بده. برای دموی در دسترس، `status` را برابر `available` بگذار. بقیهٔ وضعیت‌ها به‌جای لینک اجرا، «دمو ندارد» نشان می‌دهند.

## منابع

نام‌ها و لینک‌ها از ریپوهای عمومی [abolfazlj10](https://github.com/abolfazlj10) گرفته شده‌اند: ToolBo، WeatherApp، calculator، TicTacToe، todo-List، IdiomYar و CPass.

در بررسی ۲۰۲۶-۱۰-۰۷، صفحهٔ ورودی شش دمو در دسترس بود؛ آدرس CPass خطای ۴۰۴ داشت. این وضعیت‌ها ثابت‌اند و به معنای پایش زنده یا آزمون کامل عملکرد پروژه‌های مستقل نیستند.

فونت وزیرمتن به‌صورت محلی استفاده شده؛ مجوز در `app/fonts/Vazirmatn-LICENSE.txt` است. هیچ کلید یا توکنی در سورس نیست.
